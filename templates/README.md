# Runnable video templates

Three original 15-second animations for different uses. Each folder is standalone, with a browser preview/editor, config, rendered example, MIT license and English/Chinese instructions.

| Template | Use case | Example | Guide |
|---|---|---|---|
| [Product UI](product-ui-15s/) | Pick → customize → export | [MP4](product-ui-15s/example.mp4) | [中文](product-ui-15s/README.zh-CN.md) |
| [Feature Demo](feature-demo-15s/) | Problem → one action → result | [MP4](feature-demo-15s/example.mp4) | [中文](feature-demo-15s/README.zh-CN.md) |
| [Product Launch](product-launch-15s/) | Introduction → benefits → call to action | [MP4](product-launch-15s/example.mp4) | [中文](product-launch-15s/README.zh-CN.md) |

Download a complete template folder and open `index.html`. Edit the preview and save the config back into that folder. Export needs Node.js 22+, Playwright Chromium and FFmpeg; see the individual guides. These are code animations of fictional products, not demonstrations of live app features or verified single-prompt model outputs.
