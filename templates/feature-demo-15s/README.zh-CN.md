# 15 秒功能演示模板

一份可以改产品名、文案、主色和截图的模板。双击打开预览，保存配置，再导出 MP4。

[查看示例视频](example.mp4) · [English](README.md) · [配置文件](config.js)

**15 秒 / 1920×1080 / 30fps / 无声 / MIT 开源许可**

示例中的 **Focus 是虚构产品**。画面为原创代码动画，不是实际应用功能，也不作为某个模型一次生成的证明。

## 一、直接预览

下载整个文件夹，双击 `index.html`。默认预览不需要安装工具、不需要账号、API Key 或服务器。

右侧可以修改：产品名、主色、开场标题、中段标题、结束标题、行动文案、展示网址，以及本模板专属字段。展开 **More copy / 更多文案** 还能修改副标题、项目名和背景颜色。

上传 PNG、JPEG 或 WebP 截图后，它会出现在结束段右侧的结果区域；截图按比例完整显示，不裁掉边缘。建议使用接近横向 16:9 的截图，竖图会留出空白。支持播放、暂停、重播和拖动进度。

## 二、保存自己的版本

1. 在页面中修改内容，拖动进度条检查开场、中段和结尾。
2. 点击 **Save config.js** 下载配置文件。
3. 用下载文件替换模板目录里的 `config.js`。
4. 刷新 `index.html`，确认修改仍然存在。

浏览器不会自动覆盖原文件。只改页面、不保存，刷新后会丢失修改。截图会嵌入配置文件，建议上传约 1600 像素宽的图片，避免文件过大。Reset 会恢复磁盘中加载的配置。

也可以用文本编辑器修改 `config.js`，例如：

```js
productName: "你的产品",
accent: "#087F73",
headline: "给好想法，一个好开场。",
editorTitle: "换成你的内容。",
endHeadline: "下一次发布，准备好了。",
cta: "开始体验",
website: "your-product.com",
```

标题建议简短。中英文都能显示；虚构界面里的固定小标签仍是英文，可在 `motion.js` 中修改。

## 三、导出示例视频

只有导出 MP4 才需要 **Node.js 22+、npm、FFmpeg**。在模板文件夹中打开终端，执行：

```sh
npm install
npx playwright install chromium
npm run render -- my-product.mp4
```

导出的 `my-product.mp4` 就在当前文件夹，参数为 H.264、1920×1080、30fps、15 秒、无音轨。第一次安装依赖和浏览器需要联网，安装后默认模板可离线渲染。

直接执行 `npm run render` 会覆盖文件夹里的 `example.mp4`，因此建议保留上面的自定义文件名。

常见问题：

- **提示找不到 ffmpeg：** 安装 FFmpeg 并加入 PATH，或用 `FFMPEG_PATH` 指定可执行文件。
- **提示缺少 Chromium：** 执行 `npx playwright install chromium`。
- **导出还是旧内容：** 确认下载的配置已替换模板目录中的 `config.js`，再重新渲染。
- **想调整画幅或时长：** 这版固定 16:9 和 15 秒，需要修改布局、时间轴与渲染参数；不是配置项。
- **想让截图里的按钮也动起来：** 当前截图是静态图片；模板负责外围的转场与动画，截图内部交互需要额外制作。

## 四、代码与检查

- `config.js`：日常改文案、颜色和截图。
- `motion.js`：画面、转场、光标与时间轴。`seek(7)` 可直接跳到第 7 秒。
- `render.mjs`：导出 MP4。
- `check.mjs`：预览与保存配置检查，运行 `npm run check`。
- `VERIFICATION.md`：实测环境及视频参数。

时间轴：0–4 秒展示待办列表；4–7.4 秒点击优先级排序、四行移动到新位置；7.4–10.8 秒保持结果；10.8–15 秒展示重点事项与行动入口。

四条待办里，第 2、4 条为高优先级，排序规则固定；改任务文案不会改变排序规则。需要改业务规则时编辑 motion.js 中的 dest 和 levels。
