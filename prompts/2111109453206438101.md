## Prompt (English)

```text
Create a single self-contained HTML file with a beautiful, colorful 3D physics scene using Three.js (load it from https://t.co/vqULHd2mcL via an import map). No physics libraries: write the physics yourself. Scene: a tall tower of at least 40 brightly colored blocks (rainbow palette) standing on a glossy floor. A heavy chrome wrecking ball on a chain swings in from the side, smashes into the tower, and the blocks tumble, collide with each other and the floor, and come to rest realistically. Blocks must never pass through the floor or each other. Include gravity, collisions, friction, and rotation. Make it cinematic: dark gradient background, soft shadows, nice lighting, and a camera slowly orbiting the scene. The ball should hit the tower within the first 3 seconds. Fill the whole browser window. Return only the code.
```
