# One-Tap Flying Mobile Game in HTML5 Canvas

## Prompt (English)

```text
Build a polished mobile game I can play in my phone's browser.

Concept: a one-tap flying game in the spirit of Flappy Bird, with its own original
character, art and name. Tap to flap, gravity pulls you down, fly through the gaps
between obstacles. Every gap you pass is +1 point. Hit anything and it's game over.

Requirements:
- One file: index.html with all HTML, CSS and JavaScript inline. No external
  libraries, images, fonts or audio files. Draw everything in code and make
  sounds with the Web Audio API.
- Built for phones in portrait. Fill the screen, respect safe areas, stay crisp on
  high-DPI screens. Tap anywhere to flap; also support mouse click and the space bar
  for desktop testing. No scrolling, zooming or text selection while playing.
- Screens: a start screen with the game's name and a "tap to start" hint, the game,
  and a game over screen with the score, the best score (saved in localStorage) and
  a restart button.
- Game feel: smooth motion that doesn't depend on frame rate, a character that tilts
  with its speed, a flap animation, parallax background layers, particles on flap
  and crash, a small screen shake on crash, and a short vibration on crash where the
  browser supports it.
- Difficulty: start forgiving, then slowly narrow the gaps and speed up as the score
  grows.
- Sound: flap, point and crash sounds, plus a mute toggle. Start audio only after the
  first tap.
- Polish: one consistent art style and color palette, a readable score at the top,
  nothing under the notch or the home bar.

When you're done, check that the game actually works and fix anything that's broken.
Then tell me in a few lines what you built and how to run it.
```
