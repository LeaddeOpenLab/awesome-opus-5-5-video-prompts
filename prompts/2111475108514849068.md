## Prompt (English)

```text
# Task: Create a product promo video for "Gouo Canvas"

## Background
Gouo is my AI image platform (GitHub: zhs1234/gouo-canvas) featuring three workspaces: Image Generation, Infinite Canvas, and Creative Agent. Clone the repo and inspect src/components/landing/ (LandingPage.tsx, landing.css) and docs/zh-CN/user-guide.md before starting.

## Specs
- 16:9, 1920x1080, 30fps, ~60s, MP4 (H.264)
- No voiceover or BGM; subtle interaction SFX only

## Assets (Important)
- All generated images must use real landing preview files: public/landing/preview-{1..3}-{1..4}.webp
  - Set 1: Steak product shot
  - Set 2: Embroidered bird and flower illustration
  - Set 3: Rainy night city street
- Display real prompts verbatim; do not fabricate
- Disallow public/inspiration images and docs sketch screenshots
- Do not fake unrendered outputs (e.g. inpainting shows brush only)
- Add disclaimer text: "UI simulated · Images genuinely generated with Gouo"

## Visual Style
- Intro/Outro: Warm fluid gradient fog with film grain; title reveals from mask; floating framed cards
- Product sections: HTML re-creation of dark UI (sidebar, credits, inputs, canvas, Agent chat)
- Palette: Paper #faf8f3, Ink #171719, Accent #c26855; ease cubic-bezier(0.23, 1, 0.32, 1)
- Progressive image reveal animation
- Glassmorphism caption card in lower-left

## Simulated Cursor
- Smooth movement, click squash with ripple, hover states, drag-and-drop targeting dynamic element positions

## Storyboard
1. Intro (0-6s): Landing hero, "From Inspiration / To Image", click CTA
2. Image Generation (6-27s): Type steak prompt, select 4 images, send, progressive reveal, favorite, launch inpainting brush
3. Infinite Canvas (27-41s): Connect text node to config node, generate 2 embroidery images, zoom out to minimap
4. Creative Agent (41-55s): Prompt agent for rainy night city, tool execution cards stream, canvas updates with new nodes
5. Outro (55-63s): Fog background, closing tagline, CTA click
Credits balance decrements accurately throughout.

## Sound Design
- Synthesized procedural SFX (subtle clicks, light typing, soft tonal chimes, breath transitions, ending chord); peak ~ -15 dBFS

## Implementation
- Single HTML page + deterministic timeline: render(t)
- Playwright frame-by-frame capture, ffmpeg encoding
- Python (numpy/scipy) audio synthesis merged into final video
```
