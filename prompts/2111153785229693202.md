## Prompt (English)

```text
Build a single self-contained HTML file using Three.js: an interactive 3D deep-sea bioluminescent jellyfish simulation with squishy soft-body physics. 
Requirements:
- Visuals: Dark abyss environment with glowing suspended marine snow particles. The jellyfish bell must use a translucent, refractive shader with subsurface scattering (SSS) and pulsing neon emissive veins.
- Physics: When the user clicks/drags the jellyfish bell, it should deform elastically like soft jelly with satisfying wobble and spring-back damping. Tentacles should follow realistically using a verlet or chain-physics solver.
- Interaction: Click-drag to pull and bounce the jellyfish; mouse move controls the camera orbit. Include a minimal HUD overlay showing swim velocity and a toggle for wireframe/glow intensity.
- Single file only, no external 3D models or textures, 60 FPS performance.
```
